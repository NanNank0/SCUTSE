## 图文件格式

首行是`n m directed`：n为顶点数（1到100），m为输入边数，directed为1表示有向图、0表示无向图。随后给出n个用空白分开的顶点名，名称不能重复且不能含空白。后面恰好m组三元组`u v weight`，顶点编号从0开始，权值为非负int。

无向图只输入一条无向边，构建时自动写入两个方向。禁止重复边；无向边的反向重复也会被拒绝。允许零权边和自环。输入格式、端点、权值或边数错误会在结果区提示，避免静默生成错误图。

## 两种存储如何实现

MatrixGraph内部使用二维vector，每个格子是optional<int>。nullopt表示没有边，数值0表示真实存在的零权边；这样不会误删乐谱换海报这条免费边。空间O(V²)，扫描某顶点的所有邻居为O(V)。

ListGraph内部使用vector<list<Edge>>，每个顶点对应一条真实链表；Edge保存终点与权值。每次插入按终点编号递增定位，使邻接矩阵与链表的访问顺序一致。空间O(V+E)，扫描邻居为O(outdegree)。构建时的有序插入另有查找成本，报告中的遍历复杂度从图已经建立之后计算。无向图的每条边会存两条弧，渐进复杂度不变。

neighbors是两个图类型共同提供的接口。模板函数bfs、dfs、topological和dijkstra接收同一种接口，实际访问各自的矩阵或链表，窗口不会把其中一种结果直接复制为另一种。

## BFS 宽度优先搜索

先把起点标记并入队。循环取出队头，输出该顶点，把尚未访问的邻居在标记后入队。标记放在入队时，避免多个父结点将同一顶点重复入队。完成起点所在分量后，按编号检查其他未访问顶点，继续搜索，因此能覆盖不连通图。

traversal.txt有8个顶点A到H，其中H孤立，从A开始结果为：

```text
A → B → C → D → E → F → G → H
```

在图已经建立的前提下，邻接链表为O(V+E)，矩阵为O(V²)；访问标记、队列与输出合计O(V)辅助空间。这里返回的是覆盖全图的遍历森林顺序，H不表示从A可达。

## DFS 深度优先搜索

访问顶点后立即标记并输出，对每个未访问邻居递归搜索，直到走到尽头再回溯。外层同样处理所有未访问分量。相同文件从A开始，结果为：

```text
A → B → D → G → E → C → F → H
```

链表时间O(V+E)，矩阵O(V²)。递归栈深最多V；矩阵neighbors在每层可能构造临时邻居数组，遍历全图时这些活动数组的峰值总量最坏可达O(V²)；链表版本neighbors返回引用，不复制链表，辅助空间O(V)。

## 拓扑排序与有向图判环

采用Kahn算法。统计所有顶点的入度，将初始入度为0的顶点按编号加入FIFO队列。每次弹出一个顶点并输出，再把它的所有出边终点入度减1，恰好减到0时入队。队列空后，如果输出数等于V，则无环，输出是一种合法拓扑序；少于V则存在有向环。

dag.txt的输出为`A B C D E F`，六个顶点全部输出。cycle.txt在此基础上加入E→B，形成B→D→E→B，只有A能够先输出，随后队列变空，输出数为1/6，因此有环。自环同样会阻止该顶点入队。

有环时已经输出的列表是部分处理结果，不能称为完整拓扑序。未输出的顶点既可能属于环，也可能只是被环阻塞；Kahn算法本身没有给出环上的准确顶点集合。

链表时间O(V+E)，矩阵O(V²)，入度数组、队列、输出合计O(V)辅助空间。两种表示都使用FIFO队列，因此相同邻接访问次序下结果一致。

## 换物品题如何建模

用物品作顶点，允许的交换作有向边，边权为持有当前物品者需额外支付的人民币。题目没有说明反向交换，所以不增加反向边。这里不考虑返程、出售物品或额外收入，只在题目列出的交换方案中寻找最少补款。

| 起点物品 | 终点物品 | 补款/元 |
|---|---|---:|
| 肖邦乐谱 | 周杰伦海报 | 0 |
| 肖邦乐谱 | 限量黑胶 | 50 |
| 限量黑胶 | 鼓 | 150 |
| 周杰伦海报 | 鼓 | 300 |
| 限量黑胶 | 吉他 | 200 |
| 周杰伦海报 | 吉他 | 350 |
| 鼓 | 古筝 | 100 |
| 吉他 | 古筝 | 200 |

题目中“小光愿意额外加150元”的条件被建模为当前黑胶持有人再加150元换鼓；物品转手后同样可以使用这一交换条件。此理解对应题目要求的带权有向图最短路。

所有权值非负，使用Dijkstra。初始乐谱距离0，其他为INF。小根堆弹出当前最小的暂定距离，检查过期条目后扫描出边；发现更便宜的路径就更新距离和前驱，并把新候选距离放入堆。前驱数组反向回溯可恢复物品交换路径。

两种表示得到相同结果：乐谱→限量黑胶→鼓→古筝，费用50+150+100=300元。全部顶点最短距离依次为0、0、50、200、250、300。其他三条可行路径总费用为400元、450元和550元，因此300元最小。

本实现两种存储都使用允许过期条目的小根堆，堆空间最坏O(E)，而不是固定只有V个元素。链表版时间O(V+E+(V+E)log(V+E))，简单图中常写为O((V+E)log V)；矩阵版扫描所有行要O(V²)，另加堆操作O(E log(E+1))。矩阵neighbors的临时一行只需O(V)，Dijkstra无递归，因此算法辅助空间O(V+E)。图本身的存储空间另计。

## Qt 窗口与绘图

GraphWindow负责创建输入编辑框、矩阵与链表只读展示区、算法结果区，以及GraphCanvas。点击“执行算法”后，先解析输入，再独立构建两个图类型，执行对应模板函数，最后核对并显示结果。按钮回调捕获异常，将“操作未完成”与原因追加到结果区。

GraphCanvas使用QPainter按圆周摆放顶点，绘制边、方向箭头和费用；图形只展示输入图，不参与BFS、DFS、拓扑排序或最短路计算。QApplication管理事件循环，Qt父子对象机制管理控件；图结点与边由标准容器管理。

## 测试范围

graph_tests检查指定BFS/DFS顺序、300元路径、自环、零费用边、终点不可达、非法端点、负权边、重复边和多余数据。250张固定种子的随机图中，BFS/DFS核对两种表示；判环与独立传递闭包对照；Dijkstra与Bellman-Ford松弛结果对照，并检查恢复路径的端点、边存在性和费用之和。

ui_tests通过真实控件和运行按钮，检查BFS/DFS、修改输入后的无环转有环、错误输入提示及300元交换结果。tests可用配置完成的构建目录中的ctest --output-on-failure运行。运行记录见运行结果目录。

## 命令行参数

以下假设使用本目录下的 build 作为构建目录，并在 Qt 运行库可用的终端中执行；使用其他构建目录时相应修改路径。

```powershell
./build/exp4-1/exp4_1.exe --data ./测试数据 --example traversal.txt
./build/exp4-2/exp4_2.exe --data ./测试数据 --example cycle.txt
./build/exp4-3/exp4_3.exe --data ./测试数据 --example exchange.txt
```

--capture后接PNG路径可保存实际窗口；--export后接txt路径可保存窗口计算得到的文字结果。exp4-3将起点控件作为源点，最后一个顶点作为目标；exchange.txt已将乐谱放在0号、古筝放在5号。BFS与DFS访问邻居的顺序会影响遍历序列，本实验统一按编号递增访问。
