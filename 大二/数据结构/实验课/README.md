## 使用方法

各实验保留独立 CMake 工程。在 Qt Creator 中打开相应实验目录的 CMakeLists.txt，选择 Qt 6、C++17 的匹配套件构建和运行；详细步骤见各目录的运行说明。排序计时使用 Release 构建。

源码、报告、任务书、模板、测试数据与实际运行结果按实验目录整理。README 保留在仓库中方便学习，课堂提交包和本机生成文件不上传。
