## 构建与运行

使用 Qt 6.5 以上、C++17 与 CMake 3.21 以上。已在 Windows 11、Qt 6.11.1、MinGW GCC 13.1 的 Release 构建下运行。

1. 在 Qt Creator 中打开本目录的 `CMakeLists.txt`
2. 选择与 Qt 库匹配的 MinGW 64 位套件，构建类型选 Release
3. 构建后选择 `SortCompare` 或七个英文算法名 运行

也可以打开各题目录内的 CMakeLists.txt，但要保留完整实验目录及同级 common、测试数据。构建时会将测试数据复制到构建目录，Qt Creator 默认工作目录下可直接读取。

## 数据与验证

原始测试数据在 [测试数据](测试数据/)，实际运行截图、输出和测试记录在 [运行结果](运行结果/)。排序耗时应在 Release 构建下比较，重新测量后需同步更新报告中的数字。

在 Qt 运行库可用的终端，使用实际构建目录执行：

```powershell
ctest --test-dir build --output-on-failure
```
