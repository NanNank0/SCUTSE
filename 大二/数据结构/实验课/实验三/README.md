# 实验三 内排序算法的实现及分析

本实验沿用实验一、二的 C++17、Qt Widgets 和 CMake 结构。七个算法分别放在英文目录中，算法头文件不依赖 Qt；窗口、读写和计时放在 common 中。报告给出真实的三次测量、均值与折线图，原始数据和测量明细可逐项核对。

## 统一接口与输入

所有算法使用 `void Algorithm(std::vector<unsigned>& a)`，原地修改传入序列。unsigned 在本环境为32位，允许0到4294967295。测试数据为0到999999，允许重复，按自然数包含0的约定处理。使用 mt19937，种子20261118，依次生成三组数据；生成器结果直接对1000000取模，保证固定种子下不依赖 uniform_int_distribution 的实现细节。

七个算法读取完全相同的三个文件。`std::sort` 只生成用于核对的期望序列，不用于实现这七个算法。每次结果都与期望序列完整比较，既检查有序性，也检查元素是否丢失或重复。

## 插入排序

循环到下标i时，前缀[0,i)已经有序。保存a[i]，将前缀中比它大的值逐个右移，最后填入空位。条件使用严格大于，因此相等元素不交换先后顺序。已排好序时每个元素只做一次比较，为O(n)；一般与最坏情况O(n²)，辅助空间O(1)，稳定。

## 冒泡排序

比较相邻元素，逆序就交换。每一趟结束时，当前范围的最大值到达末端，下一趟少处理一个末端位置。一整趟没有交换就说明已经有序。最好O(n)，平均和最坏O(n²)，辅助空间O(1)，稳定。

## 选择排序

扫描未排序后缀，找到最小值并与当前起点交换。即使输入已经有序，每轮仍扫描后缀，因此最好、平均、最坏均为O(n²)。辅助空间O(1)，不稳定。例如2a、2b、1交换后可能成为1、2b、2a。

## 归并排序

递归将区间分为两半，分别排序后使用临时数组合并，再复制回原区间。合并时相等优先取左边，以保留稳定性。各层总工作量O(n)，共O(log n)层，时间O(n log n)；临时数组O(n)，递归栈O(log n)，总辅助空间O(n)。本实现没有“已序区间直接跳过”的优化，最好情况仍为O(n log n)。

## 快速排序

从区间首、中、末三个值中取中位数作为轴值。lt之前小于轴值，lt到i之间等于轴值，gt之后大于轴值，中间部分尚未处理。扫描完成后只需处理小于和大于两个区间。

三数取中改善常见有序输入，三路划分避免大量重复值反复递归，但不能保证所有输入的时间都为O(n log n)。平均O(n log n)，最坏O(n²)；全相等输入只需一轮线性扫描。本实现递归较短区间、循环处理较长区间，最坏辅助栈为O(log n)。快速排序不稳定。

## 堆排序

先从最后一个非叶子结点向前建最大堆，总成本O(n)。反复交换根和末尾元素，缩小堆范围，再向下筛选恢复最大堆。平均和最坏O(n log n)，辅助空间O(1)，不稳定。大量相等值可使本实现的筛选提前停止，因此这类输入不应机械地视为每次都下沉完整堆高。

## 基数排序

每次按一个字节进行稳定计数分配，低位到高位依次处理，桶数为256。先统计各桶数量，变为桶的起始偏移，再按原顺序分配到临时数组。处理最高有效字节后停止，至多4趟；本实验数据小于1000000，需要3趟。时间O(d(n+256))，辅助空间O(n+256)，稳定。它利用整数位结构，不属于基于比较的排序。

## 三次计时如何保证可比较

每个算法每种规模先预热一次，再正式测三次；预热不记录到表中。每次从原始输入复制一份，复制在计时之前；计时只包围算法函数，包含算法自己申请临时空间的开销。校验、文件读写和界面刷新均在计时之外。使用 steady_clock，结果转为纳秒。Release构建使用编译器的O3优化。

timings.csv有63行记录（7×3×3），列为algorithm、n、run、time_ns、verified。averages.csv有21行均值。均值用未舍入的三个整数纳秒计算后保留两位小数。窗口可读取CSV展示报告中的同一组测量；点击“运行三组测试”会重新计时，数字可能变化，导出后需同步更新报告。

折线图横坐标是实际规模n，纵坐标为平均耗时ms，采用线性坐标。完整图展示全部七种算法；局部图只显示四种较快的算法，避免被二次排序的量级遮住。1ms=1000000ns。

三次测量样本较少，调度、CPU频率、缓存和其他程序会影响数值。该实验支持比较本机、这三组输入的现象，复杂度结论仍应根据代码中的循环与递归分析。

## Qt 窗口如何调用算法

main创建QApplication，调用styleApp设置字体和控件样式，然后创建SortWindow并进入事件循环。单算法窗口传0到6，比较窗口传-1。点击“运行三组测试”后，按钮的clicked信号触发lambda，lambda调用benchmark，refresh再把三次原始耗时与均值写到只读QTableWidget。QPlainTextEdit显示输入与排序后的前24个值以及完整校验结论。

目录选择和导出使用QFileDialog。读数使用QFile与QString，支持本机的中文目录；数据不是合法32位自然数、规模不匹配或读写失败时会显示“操作未完成”。输入复制和绘制表格不属于排序算法本身的开销。

## 自动检查

sort_tests使用空序列、单元素、重复值、升序、降序、UINT_MAX及固定种子随机输入，共1099个“算法×用例”组合，逐一与std::sort比较。ui_tests创建真实Qt窗口并点击运行按钮，检查21行结果和校验反馈。在配置完成的构建目录运行ctest --output-on-failure即可。

## 命令行复现

以下假设使用本目录下的 build 作为构建目录。在 Qt 运行库可用的终端，以本实验目录为工作目录运行；Qt Creator 使用其他构建目录时，相应修改程序路径：

```powershell
./build/SortCompare.exe --generate --benchmark --data ./测试数据 --out ./运行结果
./build/InsertSort/InsertSort.exe --data ./测试数据 --results ./运行结果/timings.csv
```

--generate按固定种子重建数据；--benchmark只测量并导出，不显示窗口；不带--results时窗口启动会进行实测；--capture 后接PNG路径可保存实际窗口。正式比较请避免同时进行其他高负载工作。
