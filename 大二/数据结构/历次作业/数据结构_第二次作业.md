## Exercise 3.28

A deque is a data structure consisting of a list of items on which the following operations are possible

* push(x): Insert item $x$ on the front end of the deque.
* pop()： Remove the front item from the deque and return it.
* inject(x): Insert item $x$ on the rear end of the deque.
* eject(): Remove the rear item from the deque and return it.

Write routines to support the deque that take $O(1)$ time per operation

### Solution

那既然是要写一个双向队列，那我们可以以链表为基础，加一个前后指针来解决
主要是要求时间复杂度为 $O(1)$ ，如果删除节点需要重新找节点，需要再次遍历这一个列表，会变成 $O(n)$

```C++
// Language: C++
#include<bits/stdc++.h>
using namespace std;
//定义双向链表
class Deque{
private:
    struct Node{
        int data;
        Node* prev;
        Node* next;
        Node(int v): data(v),prev(nullptr), next(nullptr){}
    };

    Node* front;
    Node* rear;
public:
    // Constructor & Destructor
    Deque(): front(nullptr), rear(nullptr){}
    ~Deque(){
        while (front!=nullptr){
            Node*p = front;
            front = front-> next;
            delete p;
        }
        rear = nullptr;
    }

    bool empty() const{
        return front == nunllptr;
    }

    // push(x): Insert item $x$ on the front end of the deque.
    // 这里的思路是将一个新的节点放在front前，将它的next指针指向front指向的节点
    // 然后让front的prev指向新节点，最后处理一下让front作为p就好了
    void push(int x){
        Node*p = new Node(x);
        p->next = front;
        if(front != nullptr){
            front->prev = p;
        }else {
            rear = p;
        }
        front = p;
    }

    // pop()： Remove the front item from the deque and return it.
    // 这里的思路要先判断这个队列是否非空，然后将front复制一个p指针
    // 把p给delete了，把front和prev处理一下
    int pop(){
        if(empty()){
            exit(1); // 这里好像不应该这么写，直接退出报1太粗暴了，但是我不会其他写法了qwq 
        }
        Node* p = front;
        int x = p->data;
        front = p->next;
        if(front!= nullptr){
            front->prev = nullptr;
        }else{
            rear = nullptr;
        }

        delete p;
        return x;
    }

    // inject(x): Insert item $x$ on the rear end of the deque.
    // 这里的思路和 push 的思路是差不多的
    int inject(int x){
        Node* p = new Node(x);
        p->prev = rear;
        if(rear != nullptr){
            rear->next = p;
        }else{
            front = p;
        }
        rear = p;
    }

    // eject(): Remove the rear item from the deque and return it.
    // 不再过多赘述
    int eject(){
        if(empty()){
            exit(1);
        } 
        Node* p = rear;
        int x = p->data;
        rear = p->prev;
        if(rear!=nullptr){
            rear->next=nullptr;
        }else{
            front = nullptr;
        }

        delete p;
        return x;
    }
}
```

```C++
struct Node{
    int data;
    Node* next;
    Node(int d) : data(d), next(nullptr){}
};
class SALIST{
private:
    Node* head;
public:
    // Constructor
    SALIST() : head(nullptr){}

    // 这个在前端插入就很水了，毕竟是链表有没有下标，直接新建一个节点当成头节点就行了哈哈
    void insertFtont(int x){
        Node* p = new Node(x);
        p->next = head;
        head = p;
    }

    // 查找
    bool find(int x){
        // 依旧双指针起手
        Node* prev = nullptr;
        Node* curr = head;

        // 用curr遍历一下这个链表，遇到就停下来
        while(curr != nullptr && curr->data != x){
            prev = curr;
            curr = curr->next;
        }
        
        if(curr == nullptr) return false;   // Not found
        if(prev != nullptr){
            prev->next = curr->next;
            curr->next = head;
            head = curr;
        }
        return true;
    }
}
```

### Solution c

英文不是很好的来了，这里是要证明访问概率最高的元素期望上会靠近前端   （~~我错了概率论与数理统计我没好好学~~）

> 假设元素 $i$ 被访问的概率是固定的 $p_i$，且 $\sum_ip_i = 1$

对于任意两个元素 $i$ 和 $j$， 他们的**相对顺序**只会在这两个的其中一个被访问的时候发生改变（显然）

因此， $i$ 在 $j$ 前面的概率就等于**最近一次在 $\{i,j\}$ 中访问到的是 $i$ 的概率**

那么又由于每次的访问都是独立的，上述所说的概率应当为：

$$P(i,j) = \frac{p_i}{p_i+p_j}$$

显然，只有当 $p_i > p_j$ 的时候会有： $$\frac{p_i}{p_i+p_j} > \frac 12$$

翻译一下：**访问概率更高的元素有大于一半的概率在另一个元素之前**

那么现在可以大胆一点，直接假设 $i^*$ 就是访问概率最高的元素， 即对任意的 $j\ne i^*$ ，都有 $p_{i^*} > p_j$，那么显然有$$\forall j\ne i^*, P(i^*在j前面)=\frac{p_{i^*}}{p_{i^*}+p_j}\ge\frac12$$

或者说元素 $i$ 的期望位置为： $$E[pos(i)]=1+\sum_{j\ne i}\frac{p_j}{p_i+p_j}$$

显然，当这个 $p_i$ 越大的时候，这个每一项 $\frac{p_j}{p_i+p_j}$ 就会越小，所以 $E[pos(i)]$ 就会越小

因此我们可以直接得出结论：**访问概率最高的元素期望位置最靠前**，即期望上靠近前端

## 推导循环队列长度公式：length== ((rear+maxSize)-front+1)%maxSize

ok啊，我们先确认一下每个代表的都是什么

* `rear` 指向队尾元素
* `front` 指向对头元素
* `maxSize` 表示这个循环队列的最大长度

首先假设一下**不循环**的队列，一定会有 $front < rear$ ，这是**显而易见**的

那下一步我们考虑一下**循环**队列，会出现 $rear < front$，这是因为在循环中front进了一次循环，而rear没有进循环

所以我们在 $rear-front$ 的时候加上一个 $maxSize$ 来保证这个数是正的

显然，如果只是 $rear-front$ 也不一定对，例如从下标为1到下标为2的数据，根据我们的公式算出来的结果应当是 $2_{(rear)}-1_{(front)}=1$ 但实际上并不是，所以我们需要再+1来补上这一块

那我问你，为什么后面要取模？很显然，当 $front = 0$ 的时候，$rear + maxSize + 1 > maxSize$，但是我们的队列长度是不可能超过这个 maxSize 的，所以我们需要给我们的结果对 maxSize 取模来限制一下大小

综上，我们可以推出循环队列的长度公式：$$length = ((rear + maxSize)-front+1)\%maxSize$$
