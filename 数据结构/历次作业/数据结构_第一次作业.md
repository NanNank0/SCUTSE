## 一、斐波那契数列

### 递归实现

    #include <bits/stdc++.h>
    using namespace std;
    int fbnq(int num);      //prototype
    int main(){
        int n;
        cin >> n;
        cout << fbnq(n) << endl;
        return 0;
    }

    int fbnq(int num){
        if (num == 1 || num == 2) return 1;
        return fbnq(num-1) + fbnq(num-2);
    }

* 时间复杂度估计：这个是没有制表的方法，所以每次调用n都会用两次这个方法
* 所以用大O表示的话时间复杂度应该是 $ O(2^n) $

### 循环实现

    #include <bits/stdc++.h>
    using namespace std;
    int main(){
        int n, ans;
        cin >> n;
        vector<int>fbnq(2, 1);
        for(int i=2; i<n; i++){
            fbnq.push_back(fbnq[i-1]+fbnq[i-2]);
        }
        cout << fbnq[n-1] << endl;
        return 0;
    }

* 时间复杂度估计：这个只用循环n次，所以时间复杂度应当是 $ O(n) $

## 二、Exercise 2.7

For each of the following six program fragments:

b. Implement the code in the language of your choice, and give the running time for several values of N.  
c. Compare your analysis with the actual running times.

### (1)

    sum = 0;
    for (i = 0; i < n; ++i)
        ++sum;
    
* 这里循环了n次，所以时间复杂度应当是 $ O(n) $

### (2)

    sum = 0;
    for (i = 0; i < n; ++i)
        for (j = 0; j < n; ++j)
            ++sum;

* 这里一共两层循环嵌套，每层循环执行了n次，所以时间复杂度应当是 $ O(n^2) $

### (3)

    sum = 0;
    for (i = 0; i < n; ++i)
        for (j = 0; j < n * n; ++j)
            ++sum;

* 这里一共是两层循环嵌套，$ i $循环$n$次，$j$循环$n^2$次。所以时间复杂度应当是$O(n^3)$

### (4)

    sum = 0;
    for (i = 0; i < n; ++i)
        for (j = 0; j < i; ++j)
            ++sum;

* 这里也是两层循环嵌套，$i$循环$n$次，$j$循环$i$次，这里的$sum$会被执行$\frac {n^2}2$次，所以时间复杂度应当是$O(n^2)$

### (5)

    sum = 0;
    for (i = 0; i < n; ++i)
        for (j = 0; j < i * i; ++j)
            for (k = 0; k < j; ++k)
                ++sum;

* 这里是三层循环嵌套，$i$循环$n$次，$j$循环次数应当是$\sum i^2= \frac{n(n+1)(2n+1)}{6}$，量级是$n^3$，$k$循环次数应当是$j$
* 所以时间复杂度应当是$O(n^5)$

### (6)

    sum = 0;
    for (i = 1; i < n; ++i)
        for (j = 1; j < i * i; ++j)
            if (j % i == 0)
                for (k = 0; k < j; ++k)
                    ++sum;

* 这里是三层循环嵌套，$i$循环$n$次，$j$循环次数应当是$\sum i^2= \frac{n(n+1)(2n+1)}{6}$，量级是$n^3$
* 但是这里只有j是i的倍数的时候才会进入第三层循环，而在$j<i^2$中只有i个数符合要求
* 所以对于一个固定的 i，内层执行次数应当是$\frac{i^3-i^2}2$，那么总的时间复杂度应当是$O(n^4)$
